# Multivendor MERN Ecommerce

A full-stack ecommerce platform built using the MERN stack.

## Tech Stack

Frontend: React  
Backend: Node.js + Express  
Database: MongoDB

## Project Structure

frontend/ - React application  
backend/ - Express API server

## Installation

### Backend

cd backend  
npm install  
npm start  

### Frontend

cd frontend  
npm install  
npm start  

## Deployment

Frontend: Vercel  
Backend: Render  
Database: MongoDB Atlas
